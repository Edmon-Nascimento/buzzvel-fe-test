# Luma — Learning Platform

A responsive landing page for **Luma**, a learning platform designed to connect students and teachers through courses, practical learning experiences, and community.

This project was developed as part of the Buzzvel Front-End Engineer technical challenge.

## Overview

The goal of this project was to recreate the provided Luma landing page design while ensuring a responsive, accessible, and maintainable implementation.

The application includes multiple sections presenting the platform, its courses, learning process, community, and contact information.

## Features

- Responsive layout for desktop, tablet, and mobile devices.
- Reusable and typed React components.
- Responsive navigation menu.
- Course and category presentation sections.
- Learning process and community sections.
- Contact form interface.
- Responsive images and optimized assets.
- Semantic HTML structure.

## Tech Stack

- **Next.js 16** — React framework.
- **React** — UI library.
- **TypeScript** — Static typing.
- **Tailwind CSS 4** — Utility-first styling.
- **ESLint** — Code quality and linting.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Edmon-Nascimento/buzzvel-fe-test.git
```

Navigate to the project directory:

```bash
cd buzzvel-fe-test
```

Install the dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

Create an optimized production build:

```bash
npm run build
```

### Linting

Run ESLint:

```bash
npm run lint
```
